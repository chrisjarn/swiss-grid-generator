# Messages

Authored product text lives under `webapp/messages/en/`.

## Structure

```text
messages/
├── en/
│   ├── app.json
│   ├── ui/
│   │   ├── common.json
│   │   ├── shell.json
│   │   ├── panels.json
│   │   ├── preview.json
│   │   ├── editor.json
│   │   ├── export.json
│   │   └── status.json
│   └── content/
│       ├── legal.md
│       └── manual.md
├── en.json
└── index.ts
```

- `en/app.json` contains product metadata and seeded document content.
- `en/ui/common.json` contains shared actions and nouns.
- `en/ui/shell.json` contains the top bar, global shortcuts, and shell-owned dialogs.
- `en/ui/panels.json` contains settings, project, preset, account, legal, and feedback panels.
- `en/ui/preview.json` contains canvas interaction hints, preview feedback, tours, and layout tooltip chrome.
- `en/ui/editor.json` contains paragraph, typography, symbol, placeholder, color, image, and overlay editor strings.
- `en/ui/export.json` contains export dialog, vector metadata, and export progress strings.
- `en/ui/status.json` contains cross-feature notices, auth, cloud, save, and activity states.
- `en/content/*.md` contains legal and manual prose. Full documentation, tooltip guidance, and the feature inventory live in root `DOCUMENTATION.md`.
- `en.json` is generated by `npm run messages:generate` and must not be edited by hand.
- `index.ts` exports the typed locale bundle and `MessageKey` leaf-path type.
- Source messages are authored in normal sentence/label case; the GUI shell applies lowercase presentation through CSS.

Application code must read messages through `webapp/lib/i18n`, not by importing locale JSON directly.

## Examples

```ts
import { translateMessage } from "@/lib/i18n"

translateMessage("ui.panels.grid.title")
translateMessage("ui.export.dialog.filename")
translateMessage("ui.status.cloud.synced")
```

```tsx
import { useTranslation } from "@/lib/i18n"

const { t } = useTranslation()

t("ui.shell.topBar.actions.export.tooltip")
t("ui.editor.paragraph.rows")
```
