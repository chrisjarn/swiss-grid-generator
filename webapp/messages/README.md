# messages

authored product text lives under `webapp/messages/en/`.

- `en/ui/*.json` contains short interface messages.
- `en/content/*.md` contains long-form help, tooltip, legal, and manual prose.
- `en.json` is generated by `npm run messages:generate` and must not be edited by hand.

application code must read messages through `webapp/lib/i18n`, not by importing locale json directly.
