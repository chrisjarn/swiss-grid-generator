# EDITORIAL.md

**Editorial Voice & Language Guidelines**  
**Swiss Grid Generator**  
*Version 1.0 — May 2026*

## Core Editorial Principle

All text in Swiss Grid Generator must feel like it was written by a **master Swiss typographer** — calm, precise, understated, and authoritative.

> "Every stroke must be there for a reason."  
> — Tactile Brutalism

## 1. Tone

- Calm and serious
- Precise and economical
- Respectful of the user’s intelligence
- Understated confidence (Dieter Rams influence)
- Never casual, never marketing-like, never playful

## 2. Language Rules

- Prefer **brevity** — remove every unnecessary word.
- Use **typographical terminology** naturally when it adds clarity.
- Lowercase for most UI labels and navigation (Braun influence).
- No exclamation marks. No emojis in the interface.

## 3. Vocabulary & Preferred Terms

| Concept                    | Preferred Term                | Avoid                              |
|---------------------------|-------------------------------|------------------------------------|
| Grid                      | modular field                 | grid structure, grid settings      |
| Baseline                  | baseline rhythm               | baseline grid                      |
| Margins                   | margins / progressive margins | margin settings                    |
| Columns / Rows            | columns, rows                 | grid columns                       |
| Leading                   | leading                       | line spacing                       |
| Type Scale                | type scale                    | font sizes                         |
| Layout                    | page plan / canonical page plan | layout, design                   |
| Empty State               | empty / no pages              | nothing here yet                   |

## 4. Tone Examples by Type

### Tooltips & Help Texts
| Context                        | Weak                              | Good (Recommended)                  |
|--------------------------------|-----------------------------------|-------------------------------------|
| Margin adjustment              | "Click to change margin"          | "progressive margins"               |
| Baseline                       | "Adjust line spacing here"        | "baseline rhythm"                   |
| Modular field                  | "Change the grid layout"          | "modular field"                     |
| Keyboard shortcut hint         | "Press Cmd+Z to undo"             | "undo last change"                  |

### Error Messages
| Context                        | Weak                              | Good (Recommended)                  |
|--------------------------------|-----------------------------------|-------------------------------------|
| Export failed                  | "Oh no! Export failed"            | "export failed"                     |
| Invalid value                  | "Please enter a valid number"     | "invalid measure"                   |
| Missing file                   | "File not found. Try again."      | "file not found"                    |
| Page plan conflict             | "Something went wrong with the plan" | "canonical page plan conflict"   |

### Success / Confirmation States
| Context                        | Weak                              | Good (Recommended)                  |
|--------------------------------|-----------------------------------|-------------------------------------|
| Document saved                 | "Document saved successfully! 🎉" | "document saved"                    |
| Export completed               | "Your files have been exported"   | "export complete"                   |
| Page plan updated              | "Layout updated successfully"     | "canonical page plan updated"       |
| Changes applied                | "All changes applied"             | "field updated"                     |

### Status Messages
| Context                        | Weak                              | Good (Recommended)                  |
|--------------------------------|-----------------------------------|-------------------------------------|
| No changes                     | "Nothing has changed"             | "field unchanged"                   |
| Grid applied                   | "Grid applied to all pages"       | "modular field applied"             |
| Baseline active                | "Baseline is now active"          | "baseline rhythm active"            |

## 5. Do’s and Don’ts

**Do:**
- Write like a master typographer who respects the user’s time.
- Use precise typographic terms where they improve clarity.
- Keep text short and functional.
- Maintain consistent lowercase style for UI elements.

**Don’t:**
- Use marketing language or enthusiasm
- Add exclamation marks
- Be overly friendly or explanatory
- Use vague software jargon

## 6. Capitalization

- UI labels, buttons, menu items → **lowercase** (default)
- Panel titles and major sections → lowercase unless proper noun
- Brand name → "swiss grid"

## 7. References

- Dieter Rams / Braun design philosophy
- Josef Müller-Brockmann — *Grid Systems in Graphic Design*
