**Editorial Voice & Language Guidelines**  
**Swiss Grid Generator**  
*Version 1.1 — May 2026*

## Core Editorial Principle

All text in Swiss Grid Generator must feel like it was written by a **master Swiss typographer** — calm, precise, understated, and authoritative.

> "Every stroke must be there for a reason."  
> — Tactile Brutalism

## Interaction Philosophy

**Hover. Observe. Commit.**

This is the fundamental interaction model of the application:

- **Hover** → live preview updates instantly
- **Observe** → the user evaluates the change on the canvas
- **Commit** → deliberate action locks in the decision

All UI text must support this calm, considered flow. Language should guide without rushing, inform without overwhelming.

Author interface copy in normal sentence/label case. Lowercase is a visual presentation rule applied by the GUI CSS layer, not a source-text requirement.
